# 📚 Book Management — Angular & JSON Server

A web application developed with **Angular** for managing a collection of books through a REST API powered by **JSON Server**.
The project includes a **user registration and login system**, protected routes, and complete CRUD operations for managing books. All application data is stored in a `db.json` file and accessed through HTTP requests.
This project was created to practice building an Angular application that communicates with a REST API, while implementing **CRUD operations, forms, routing, authentication, route guards, services, environments, and HTTP requests**.

## Features

* User registration and login
* Protected routes with an Angular authentication guard
* Display a list of books
* View book details
* Add new books
* Edit existing books
* Delete books
* Data management through JSON Server
* HTTP communication using Angular `HttpClient`
* Navigation between protected and public pages
* Responsive interface
